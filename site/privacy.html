Privacy policy

Last updated: 20 November 2026

Who we are

NOAgenda is free, self-hosted software. This site describes the project and links to a public demo instance.

This website

This website is static. It sets no cookies, runs no analytics and loads no third-party scripts, fonts or trackers. The web server may keep standard access logs (IP address, time, requested page) for security and troubleshooting.

The public demo

The demo exists only for trying the app. Anyone can log in with the example users shown on its login page, so treat everything in it as public. Do not enter personal or confidential data. The demo data is reset regularly. The demo uses a cookie that keeps you signed in and nothing for advertising or tracking.

Running NOAgenda yourself

If you self-host NOAgenda, you are the operator of your instance and responsible for the data in it. The software does not send your data to us.
