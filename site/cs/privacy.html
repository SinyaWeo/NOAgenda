Kdo jsme

NOAgenda je svobodný software pro vlastní hosting. Tento web popisuje projekt a odkazuje na veřejné demo.

Tento web

Web je statický. Nenastavuje cookies, neobsahuje analytiku ani skripty, písma či sledovací prvky třetích stran. Webový server může ukládat běžné přístupové logy (IP adresa, čas, požadovaná stránka) pro účely bezpečnosti a řešení potíží.

Veřejné demo

Demo slouží jen k vyzkoušení aplikace. Přihlásit se může kdokoli pomocí ukázkových uživatelů uvedených na přihlašovací stránce, proto vše v něm považujte za veřejné. Nezadávejte osobní ani důvěrné údaje. Data v demu se pravidelně obnovují. Demo používá cookie, která vás udržuje přihlášené, a nic pro reklamu nebo sledování.

Vlastní provoz NOAgendy

Pokud NOAgendu provozujete sami, jste provozovatelem své instance a odpovídáte za data v ní. Software nám vaše data neodesílá. Jiné služby kontaktuje jen tam, kde to vy nebo vaši uživatelé nastavíte, například webhooky nebo upozornění odesílaná do chatu (Slack, Discord, Teams, Mattermost); tyto zprávy obsahují text upozornění, například název úkolu, a odkaz na něj.
